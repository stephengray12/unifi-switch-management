# UniFi Switch Code

Python project for interacting with UniFi devices using the UniFi API.

## Features

- Connects to UniFi Controller
- Lists devices
- Controls switch ports
- Uses environment variables for credentials

## Requirements

- Python 3.12+
- requests
- python-dotenv
- rich

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run

```bash
python app.py
```
